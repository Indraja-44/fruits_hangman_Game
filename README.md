# fruits_hangman_Game
Python. Implemented random fruit selection, letter guessing, repeated-letter checking, lives tracking, and win/lose conditions.

A simple Hangman game developed using Python.

## 🎮 About the Project

This is a console-based Hangman game where the player has to guess a randomly selected fruit name within 6 wrong attempts.

## ✨ Features

* Randomly selects a fruit
* Allows the player to guess one letter at a time
* Tracks previously guessed letters
* Displays correctly guessed letters
* Gives the player 6 lives
* Displays ASCII hangman graphics
* Shows whether the player wins or loses

## 🛠️ Technologies Used

* Python
* Random module

## ▶️ How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open a terminal in the project folder.
4. Run:

```bash
python hangman.py
```

## 📌 Project Purpose

This project was created to practice Python programming concepts such as loops, conditional statements, lists, user input, and the random module.
